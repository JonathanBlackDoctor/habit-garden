# 04 · 핵심 사용자 플로우

개편안은 아래 6개 플로우가 **더 짧아지거나 최소한 같은 길이**여야 한다. 길어지면 안 된다.

## 1. 최초 진입

```
/login
 ├─ 구글 로그인 ─┬─ owner        → 자동 승인 → /
 │               └─ 신규         → /pending (승인 대기) → owner 승인 → /
 └─ 게스트 시작 ───────────────→ / (로컬 데이터, SignupCTA 상시 노출)

첫 진입 시 OnboardingFlow 자동 실행:
  WelcomeCarousel (소개 슬라이드)
    → SpotlightTour 4스텝: 정원 현황 → 오늘의 습관 → 하단 탭 → 습관 체크(=/habits 로 이동)
    → firstRunSetup(uid): 초보자 위젯 3개만 남기고 나머지 숨김
```

> ⚠️ 투어 3번째 스텝 카피가 낡았다 — "오늘 · 습관 · 정원 · **진척** · 더보기"라고 안내하지만 진척 탭은 이미 더보기로 옮겨졌다. 개편 시 카피 수정 대상.

## 2. 하루 루프 (가장 중요)

```
아침  /  ← 아침 브리핑: 어제 결과 + 오늘 브리프 + "어제 다짐" 실천 체크
      │
낮·밤 /habits  ← 시간대별 습관 카드에 0~5점
      │          · 0점 = 미체크, 5점 = 완벽 수행
      │          · 묶음(예: '학교') 단위 일괄 건너뛰기
      │          · 편집 모드에서 습관 추가·수정·순서 변경
      ↓
      포인트 적립 → 상단바 카운트업 애니메이션
      전부 완료 시 → CelebrationOverlay
      ↓
밤    /reflection  ← 질문 답변 + **내일의 다짐** 작성 → +20P → 하루 마감
      ↓
04:00 KST 서버 정산 (dailyReset + awardEngine)
      · 어제 마감 · 스트릭 계산 · 미완료 패널티 차감
      · 샘물 +15 (성공일 +3) · 물 준 식물 성장 · 만개 식물 수확 수익
      · AI 코치 피드백 생성
```

**정산이 밤이 아니라 새벽 4시**라는 점이 UX적으로 중요하다. 자정을 넘겨도 "어제"가 계속 열려 있다.

## 3. 정원 루프

```
/garden
 ├─ 내 정원 ─ 화단 3개 × 8칸 (최대 24 식물)
 │    ├─ 빈 칸 탭 → 상점 → 씨앗 선택 → 포인트(종별 25~80P) + 샘물 1 소비 → stage 0
 │    ├─ 식물 탭 → 물주기 (10P + 샘물 1) → **다음 04:00에 +1단계** (fast종 +2)
 │    ├─ 만개(최고 stage) → 매일 자동 수익 or 수확하기
 │    └─ 생기 낮음 → 시듦(stage↓) → stage 0에서 또 실패 시 죽음
 ├─ 상점 ─ 씨앗 심기 / 식물 해금(200~12,000P)
 ├─ 도감 ─ 종 컬렉션 (해금/미해금)
 └─ 둘러보기 ─ 다른 사용자 정원 구경 (`?view=browse`, 탭 재탭으로 토글)
```

**정원 생기(vitality/health)** 가 이 루프의 긴장감이다. 습관을 빼먹으면 생기가 깎이고(하루 최대 −40), 생기가 낮으면 식물이 시든다. "내일 정원 예보" 위젯이 이걸 **미리** 알려준다 — 벌주기 전에 경고하는 구조.

## 4. 레벨업

```
포인트 적립 → 누적 XP → useLevelUpWatcher 감지 → LevelUpModal
                                                    ├─ BloomBadge 애니메이션 (burstKey 재생)
                                                    └─ 보상: 홀수 레벨 씨앗 / 짝수 레벨 포인트 / 5레벨마다 큰 보상
```

레벨 1~30 = **6티어 × 5서브레벨**. 티어별 팔레트는 `level_desigh/README.md` 참조(Pearl Mist → Aurora).
**배지 디자인은 이번 개편 대상이 아니다** — 3차에 걸쳐 확정한 자산이다.

## 5. 신앙 (선택 기능, 기본 OFF)

```
/more → "신앙 기능" 토글 ON
   → 하단 탭에 '신앙' 추가 (탭 4개 → 5개)
   → PrayerTour 자동 실행
   → /prayers
       ├─ 기도제목 ─ 매일 9건 로테이션(신규 3건/일) · 체크 +2P · 응답 기록 +30P
       │              그룹(교회/CMF/개인) · 대상 · 잠든(dormant) 상태
       └─ 말씀 적용 (`?view=application`, 탭 재탭 토글)
              큐티/설교/LGM/묵상에서 받은 '적용'을 기록
              → 며칠간 "오늘 실천했어요" 체크 → 목표일 달성 시 완료 +20P
              → 7일 방치 시 자동 '보류(lapsed)' → 언제든 재개
              → 승인 사용자는 노트 붙여넣기 → AI가 본문·적용점·목표일 정리
```

## 6. 게스트 → 가입 전환

```
/login "가입 없이 바로 시작하기" → 로컬 데이터로 앱 전체 사용
   → SignupCTA 상시 노출("가입하고 내 정원 지키기")
   → 구글 로그인 → 데이터 이관 → 승인 대기 or 승인
```

전환 유도는 **정원을 잃는다**는 손실 프레이밍을 쓴다. 이 톤은 유지.

---

## 플로우 설계 시 지켜야 할 것

| 원칙 | 이유 |
|---|---|
| 습관 체크는 **탭 1~2회**로 끝나야 한다 | 하루 여러 번 반복하는 동작 |
| 되돌리기가 항상 가능해야 한다 | 잘못 체크해도 벌이 즉시 확정되지 않음(04:00 정산) |
| 실패를 나무라지 않는다 | 시듦은 베이지, 경고는 조용하게 |
| 보상은 즉시 보인다 | 포인트 카운트업 · 축하 오버레이 · 식물 성장 |
| 선택 기능은 숨긴다 | 신앙·위젯 9종은 기본 OFF. 첫 화면은 3개 위젯뿐 |
