  • 신앙 기능 기본 OFF사적 영역이라 의도적으로 숨긴 것
  • 30레벨 배지 디자인3차 시안 끝에 확정한 자산(level_desigh/). 개편 대상 아님

  • 위젯 순서 변경 · 숨김 기능사용자 데이터에 저장돼 있다. UI는 바꿔도 기능은 유지
  • 게스트 모드로그인 없이 전체 체험 → 가입 전환 경로
