# 01 · 제품 브리프

> **개편 전(As-Is) 자료.** 이 문서는 바꾸기 전 현재 상태를 기록한 것이다 — 제안이 아니다.
> 실제 화면은 [`screens.html`](screens.html)에서 본다.

## 한 줄 정의

> 매일 습관을 체크하고 회고하면 포인트가 쌓이고, 그 포인트로 **내 정원의 식물이 자라는** 습관 교정 PWA.

한국어 전용. 가족·친구 규모(수 명~수십 명)의 **초대제 소규모 공유 앱**이다. 대중 대상 서비스가 아니다.

## 사용자

| 유형 | 진입 경로 | 특징 |
|---|---|---|
| **Owner** | 구글 로그인 → 자동 승인 | 관리자. `/admin`에서 신규 가입 승인, 문의 답변. 신앙 기능 기본 ON |
| **승인 사용자** | 구글 로그인 → 승인 대기 → owner 승인 | 일반 사용자. 신앙 기능 기본 OFF(더보기에서 직접 켬) |
| **게스트** | 로그인 없이 "바로 시작하기" | 체험용. 데이터가 기기에만 남고 언제든 가입 유도(SignupCTA) |

**사용 맥락**: 하루 1~3회, 대부분 **한 손 · 세로 · 1~2분**. 아침(오늘 할 일 확인)과 밤(체크·회고)이 피크.
"오래 머무는 앱"이 아니라 **빨리 들어와 체크하고 정원 한 번 보고 나가는 앱**이다.

## 핵심 루프

```
습관 체크 (0~5점)  →  포인트 적립  →  씨앗 심기 / 물주기  →  식물 성장 · 수확
      ↑                                                            │
      └──────────  다음 날 아침 브리핑 · 정원 예보로 복귀 유도  ←────┘
```

부가 루프 3개가 이 위에 얹힌다:

- **회고 루프** — 밤에 회고 작성(+20P) → 다음 날 아침 "어제 다짐" 실천 체크
- **성장 루프** — 누적 포인트 → 레벨(1~30, 6티어 × 5서브) → 배지 · 해금
- **신앙 루프**(선택) — 기도제목 로테이션 · 말씀 적용 실천 추적

## 무엇이 이 앱의 감정적 핵심인가

1. **정원** — 유일한 시각적 보상. 실패하면 식물이 시들고, 방치하면 죽는다. 화려한 게임 UI가 아니라 **조용히 살아 있는 것을 돌보는 느낌**이어야 한다.
2. **연속성** — 스트릭, 생기(vitality), "내일 정원 예보". 벌은 있지만 **비난하지 않는다**. 시듦 색(`--wither`)이 빨강이 아니라 차분한 베이지인 이유.
3. **하루의 마감** — 회고를 쓰면 하루가 닫힌다. 이 순간의 만족감이 재방문을 만든다.

## 톤 & 무드

**지향**
- 자연스럽고 차분한 유기적 톤. 그린 · 흙 · 햇살 계열.
- 여백이 넉넉하고 밀도가 낮은 카드. 폰트 두께는 400/500 위주.
- 마이크로 인터랙션은 **부드럽게, 짧게**(140~380ms). 튀지 않는다.

**지양**
- 번쩍이는 네온 · 강한 채도의 게임 UI
- 붉은 경고색으로 실패를 나무라는 표현 (배지 카운트 외에는 빨강을 쓰지 않는다)
- 헤비 웨이트 폰트, 과한 이모지 남발, 느낌표 남발
- 데이터 대시보드처럼 숫자로 압도하는 화면

**카피 톤**: 존댓말, 담백함. "좋은 아침이에요" / "오늘 다 했어요 🌱" / "딱 하나만 더!" 수준의 온도.
AI 코치 응답도 과장된 칭찬 없이 사실 기반 + 한 줄 동기부여로 규정되어 있다.
